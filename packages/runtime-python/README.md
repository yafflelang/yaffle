# yaffle

The runtime for Python code generated by the [yaffle](https://yafflelang.org) compiler. yaffle
is a language for binary file formats; the compiler turns a schema into readers, writers and lazy
views. Generated modules import `yaffle`; it needs Python 3.12+ and has no dependencies.

See the [Python target documentation](https://github.com/noahcoolboy/yaffle/blob/main/docs/targets/python.md).
