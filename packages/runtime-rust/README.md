# yaffle-runtime

The runtime for Rust code generated by the [yaffle](https://yafflelang.org) compiler. yaffle is
a language for binary file formats; the compiler turns a schema into readers, writers and lazy
views. Generated crates depend on this one; it has no dependencies of its own.

See the [Rust target documentation](https://github.com/noahcoolboy/yaffle/blob/main/docs/targets/rust.md).
