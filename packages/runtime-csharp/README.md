# Yaffle.Runtime

The runtime for C# code generated by the [yaffle](https://yafflelang.org) compiler. yaffle is a
language for binary file formats; the compiler turns a schema into readers, writers and lazy
views. Generated code references this package; it targets .NET 9 and has no dependencies.

See the [C# target documentation](https://github.com/noahcoolboy/yaffle/blob/main/docs/targets/csharp.md).
